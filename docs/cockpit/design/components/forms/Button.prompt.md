Action button — use `primary` (monochrome, inverted) once per view for the main action, `secondary` for everything else, `danger` for "Arrêter".
```jsx
<Button variant="primary">Lancer un run</Button>
<Button>Comparer</Button>
<Button variant="danger">Arrêter le run</Button>
```
Sizes: sm 26px, md 32px (default), lg 38px. Never colored with the blue accent — blue means "active", not "click me".
