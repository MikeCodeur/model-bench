# Cockpit UI kit
The full click-through app lives in `/Cockpit.dc.html` (this index embeds it).
Screens: Accueil · Benchs (catalogue) · Classement · Run (live, stoppable) · Résultat (demo + prompt/code/journal, v1/v2, retouche) · Comparer (2–4, mode aveugle) · Lancer un run · Tokens.
Global: top nav, switchable breadcrumb (each level opens a sibling menu), ⌘K palette, dark/light toggle.
Composes the same visual vocabulary as `components/`.
